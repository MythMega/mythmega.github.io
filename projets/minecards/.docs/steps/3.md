# Instructions - Étape 3 : Moteur de Tirage Gacha & Données de Référence

## Objectif
Logique métier du tirage à partir des règles de rareté et des JSON de cartes.

## Fichiers
- `settings/rarity.json`, `settings/boosters/set1.json`
- `js/business/GachaEngine.js`, `js/business/BoosterManager.js`

## Spécifications

1. **`settings/rarity.json`** (poids par emplacement)
```json
{
  "1": [ { "rarity": 1, "weight": 1.0 } ],
  "2": [ { "rarity": 1, "weight": 1.0 } ],
  "3": [ { "rarity": 1, "weight": 0.5 }, { "rarity": 2, "weight": 0.3 }, { "rarity": 3, "weight": 0.2 } ],
  "4": [ { "rarity": 2, "weight": 0.5 }, { "rarity": 3, "weight": 0.3 }, { "rarity": 4, "weight": 0.2 } ],
  "5": [ { "rarity": 3, "weight": 0.4 }, { "rarity": 4, "weight": 0.35 }, { "rarity": 5, "weight": 0.25 } ]
}
```

2. **`settings/boosters/set1.json`** : `id`, `name`, `boosterModel` (chemin `.glb`), `boosterTexture`, et `cards[]` avec `id`, `name`, `rarity`, `style`, `illustration` (chemin avec `/fr/`), `set`. Les `id` doivent être uniques entre extensions (la clé de collection est `id_style`). Fournir un jeu d'exemple d'au moins 15 cartes couvrant toutes les raretés et les 2 styles.

3. **`GachaEngine.js`** : `drawPack(boosterSetData, rarityConfig): Card[]`. Tirage pondéré (normaliser les poids), puis carte au hasard parmi la rareté R. Doublons autorisés. Si aucune carte n'existe pour la rareté tirée, lever une erreur explicite.

4. **`BoosterManager.js`**
   - Charge les JSON.
   - `openBooster(setId)` :
     1. `DateSyncManager.consumeBooster()` (échec → erreur "plus de boosters").
     2. `GachaEngine.drawPack`.
     3. **Enregistrement immédiat** dans `collection` (+1 `quantity`, `firstObtainedAt` si nouvelle, `lastObtainedAt`) et mise à jour de `stats` (`boostersOpened`, `drawsByRarity`, `drawsByCard`), le tout dans **une seule transaction**.
     4. Retourne les 5 cartes (le tirage est déjà persisté : fermer l'onglet pendant la révélation ne fait rien perdre).
   - `addCardToCollection(card, quantity)` : fonction réutilisée par Redeem et Cadeaux (elle ne touche pas à `stats.boostersOpened`).

Génère le code complet.
