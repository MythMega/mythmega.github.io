# Instructions - Étape 4 : Scène 3D Booster & Animation de Flip des Cartes

## Objectif
Interface d'ouverture : booster 3D manipulable, puis révélation des 5 cartes (face cachée, une à une, effets par rareté).

## Fichiers
- `css/components/booster-3d.css`, `css/components/card-reveal.css`, `css/views/opening.css`, `css/components/modal.css`
- `js/UI/components/Booster3DRenderer.js`, `js/UI/components/CardComponent.js`, `js/UI/views/OpeningView.js`

## Spécifications

1. **`Booster3DRenderer.js`**
   - Three.js + `GLTFLoader` (chargé en module local ou CDN épinglé). Modèle `.glb`, texture issue du JSON du set.
   - Rotation tactile/souris. Un swipe ou un clic d'ouverture déclenche l'animation, puis masque le modèle.
   - Libérer les ressources (`dispose`) et stopper la boucle de rendu quand la vue n'est pas active. Prévoir un **repli 2D** (image du booster + bouton "Ouvrir") si WebGL est indisponible.

2. **`OpeningView.js`**
   - Choix du booster (extension), affichage du quota restant, bouton désactivé à 0 avec temps avant reset.
   - À l'ouverture : appelle `BoosterManager.openBooster()` (le tirage est **déjà sauvegardé**), puis lance l'animation.

3. **`CardComponent.js` & `card-reveal.css`**
   - Carte de dos, animation CSS 3D flip au clic.
   - Chemin d'image via `I18n.resolveImagePath()` (écoute `LANG_CHANGED`).
   - Raretés 1–3 : rendu classique / léger reflet. Raretés 4–5 : glow animé (box-shadow, particules dorées ou effet holo). Les couleurs viennent des variables de thème.
   - Badge "NEW" si la carte n'était pas encore possédée (à calculer avant l'écriture en base, donc renvoyé par `openBooster`).

4. Boutons **"Tout révéler"** et **"Terminer"**. "Terminer" ne fait **aucune écriture** (déjà persisté) : il ferme la scène et revient au choix de booster.

Génère le code HTML/CSS/JS complet.
