Politique de Données

Transparence totale sur l'utilisation des données et des cookies sur l'ensemble du site et des applications.

Aucune donnée collectée côté serveur

Ce site et toutes ses applications ne sauvegardent aucune donnée personnelle ou technique sur les utilisateurs.

Aucun cookie de tracking, aucun traceur analytique, aucune information n'est transmise ou stockée sur nos serveurs.

Le code complet de ce site, incluant toutes les applications, est entièrement visible et auditable en open-source sur :

github.com/MythMega/mythmega.github.io

Données stockées localement

Les seules données existantes sont stockées uniquement sur votre appareil, dans votre navigateur, sous forme de cookies ou de bases de données locales (IndexedDB). Ces données ne sont jamais transmises à un serveur. Si vous changez de navigateur, utilisez la navigation privée ou supprimez vos données de navigation, ces informations seront perdues.

1. Pokefeet

6 cookies + 3 bases de données locales

Cookies :
  • pk_best : votre meilleur score au mode marathon (valeur numérique)
  • pokefeet_language : langue sélectionnée (code ISO 2 lettres, ex: "fr", "en")
  • pk_pseudo : votre nom d'utilisateur (modifiable à tout moment dans l'application)
  • pk_cosmetic_bg : nom du fond personnalisé choisi
  • pk_cosmetic_btn : nom du style de bouton personnalisé choisi
  • pk_fast_mode : paramètre du mode rapide ("true" ou "false")
Bases de données locales (IndexedDB) :
  • PokefeetDB : scores des daily challenges et weekly challenges
  • PokefeetChallengeDB : liste des identifiants de challenges complétés
  • PokefeetDexDB : identifiants des Pokémon trouvés en daily, weekly ou challenge, avec date d'enregistrement et nombre de fois trouvés

2. Pokegg

3 cookies + 1 base de données locale

Cookies :
  • language : langue sélectionnée (partagé avec Elden Desc, code ISO 2 lettres)
  • pokedollars : valeur monétaire de votre personnage dans l'application
  • darkMode : thème de l'application ("dark" ou "light")
Base de données locale (IndexedDB) :
  • PokeggDB : identifiants des Pokémon trouvés en jeu, avec date d'enregistrement et nombre de fois trouvés

3. Elden Desc

1 cookie + 1 base de données locale

Cookie :
  • language : langue sélectionnée (partagé avec Pokegg, code ISO 2 lettres)
Base de données locale (IndexedDB) :
  • ERGussr : résultats de vos daily challenges

4. Autobingo

3 cookies

Cookies :
  • bingo_theme : thème utilisé ("dark" ou "light")
  • bingo_lang : langue utilisée ("fr" ou "en")
  • bingo_presets : suite d'URLs custom correspondant aux presets de grilles de bingo épinglés

5. Gamefinder

3 bases de données locales

Bases de données locales (IndexedDB) :
  • gamefinder-settings : paramètres utilisateur
  • gamefinder-cache : sauvegarde temporaire de la liste des jeux, liens vers images, pour une navigation fluide
  • gamefinder-profile : informations utilisateur (nom d'utilisateur local, niveau d'expérience, liste de jeux à masquer, liste de jeux à faire, liste de presets enregistrés pour la roulette)

Point essentiel

Ce site ne détient absolument aucune donnée, personnelle ou technique, sur ses utilisateurs. C'est la raison pour laquelle si vous revenez sur le site avec un autre navigateur ou en navigation privée, le site et toutes les applications n'auront aucune donnée à votre sujet : pas de scores, pas de préférences, rien.

Toutes les informations listées ci-dessus sont stockées exclusivement sur votre appareil et ne sont accessibles que par vous. Vous pouvez à tout moment supprimer ces données via les paramètres de votre navigateur.
