Découvrez Build It

Build It est un serveur survie privé sous whitelist, actuellement en version 1.21.8, qui suivra les mises à jour de Minecraft. La 5e saison s'apprête à démarrer. Au fil des quatre saisons précédentes, de nombreuses constructions ont vu le jour, réalisées par les joueurs en mode survie.



Comment rejoindre ?

Pour intégrer Build It, certaines conditions préalables sont requises :

  • Posséder Minecraft Java Edition
  • Remplir le formulaire Google
  • Passer un entretien Discord avec un administrateur
Accéder au formulaire


Hyperlapses

Certains joueurs du serveur produisent du contenu. Outre les lives, l'hyperlapse constitue le format principal. Si vous réalisez des constructions, vous pouvez vous organiser avec ces créateurs pour qu'ils produisent des hyperlapses pour votre chaîne, dans la limite de leurs disponibilités.
