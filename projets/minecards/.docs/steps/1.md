# Instructions - Étape 1 : Squelette SPA, Styles, Persistence, i18n/Thèmes & Compte local

Tu es un développeur Web Frontend Senior. Application Web "Full Client" (Vanilla JS/ES6+, HTML5, CSS3) d'ouverture de boosters de cartes. Référence : `main.md` (modèle de données §2).

## Objectif
Structure HTML5 de la SPA, CSS responsive (Mobile d'abord), wrapper IndexedDB, base i18n/thèmes, et **création du compte local (UUID) avec écran d'accueil à la première visite**.

## Fichiers à créer
- `index.html`, `css/base.css`, `css/themes.css`, `css/views/onboarding.css`
- `js/models/StorageRepository.js`, `js/classes/Card.js`, `js/app.js`
- `js/business/AccountManager.js`, `js/utils/I18n.js`, `js/utils/ThemeManager.js`
- `js/UI/views/OnboardingView.js`
- `settings/i18n/fr.json`, `settings/i18n/en.json`, `settings/config.json`

## Spécifications

1. **`index.html`**
   - Viewport : `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">`.
   - Header avec compteur de boosters (quotidiens + bonus) et horloge UTC.
   - `<section class="view">` pour : Accueil (onboarding), Ouverture, Collection, Stats, Paramètres, Cadeaux, Redeem. Une seule vue active à la fois.
   - Bottom Nav optimisée pouce. Le header et la nav sont **masqués** tant que l'onboarding est affiché.
   - Tous les textes utilisent `data-i18n="clé"`.
   - Un petit script inline lit `localStorage` (`lang`, `theme`) et pose `data-theme` sur `<body>` avant le premier rendu.

2. **`css/base.css` et `css/themes.css`**
   - `base.css` : espacements, tailles, glow, layout. Il n'utilise que des variables (aucune couleur en dur).
   - `themes.css` : 3 thèmes via `body[data-theme="dark"|"light"|"classic"]`. **Sombre est le défaut.** Chaque thème définit les mêmes variables (fond, surface, texte, accent, glow, bordure).
   - Responsive impeccable : pas de scroll horizontal, zones tactiles ≥ 44px.

3. **`StorageRepository.js`** : base `CardBoosterDB` v1, 4 ObjectStores (`collection`, `user_state`, `redeemed_codes`, `gifts_received`) tels que définis dans `main.md` §2.
   - Méthodes async : `getItem(store, key)`, `setItem(store, key, value)`, `getAll(store)`, `deleteItem(store, key)`, `clearAll()`.
   - Ajouter `transaction(stores, mode, fn)` pour permettre des opérations atomiques multi-stores (utile aux Étapes 3, 7 et 8).
   - `user_state` : les clés sont celles listées dans `main.md` §2.

4. **`Card.js`** : `id`, `name`, `rarity`, `style`, `illustration`, `set` ; getter `uniqueKey` = `${id}_${style}`.

5. **`I18n.js`** : `init(lang)`, `t(key)`, `setLang(lang)` (recharge le JSON, réapplique les `data-i18n`, émet `LANG_CHANGED`), `resolveImagePath(path)` (remplace `/fr/` par `/en/` selon la langue). Langues disponibles lues dans `settings/config.json`.

6. **`ThemeManager.js`** : `applyTheme(name)` (pose `data-theme` sur `document.body`, met à jour le miroir `localStorage`), liste des thèmes lue dans `config.json`.

7. **`AccountManager.js`**
   - `hasAccount()` : `user_state["account"]` existe.
   - `createAccount()` : génère `uuid = crypto.randomUUID()`, écrit `account`, `settings` (lang du navigateur si fr/en sinon fr, thème `dark`), `quota`, `stats`, `giftSync` (`lastCheckedLine: 1`, la ligne 1 étant l'en-tête du sheet). Appelle `navigator.storage.persist()`.
   - `getUuid()` : lecture seule. L'UUID ne doit **jamais** être modifié après création.
   - `resetAll()` : `clearAll()` + nettoyage du miroir localStorage. Le compte est alors supprimé, y compris l'UUID.

8. **`OnboardingView.js`** (affiché uniquement si `!hasAccount()`)
   - Deux gros boutons : **"Créer une nouvelle sauvegarde"** et **"Importer une sauvegarde (.save)"**.
   - Création : appelle `createAccount()`, puis démarre l'app.
   - Import : ouvre le sélecteur de fichier. Le traitement réel est branché à l'Étape 6 (`SaveFile.importFromFile`). En attendant, le bouton affiche "bientôt disponible".
   - Sélecteur de langue accessible dès cet écran.

9. **`app.js`** : ordre de démarrage → ouvrir la DB → `hasAccount()` → si non : onboarding et arrêt → si oui : charger `settings`, `I18n.init`, `ThemeManager.applyTheme`, puis afficher le routeur SPA.

Génère le code complet et fonctionnel.
