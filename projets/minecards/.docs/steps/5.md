# Instructions - Étape 5 : Vues Collection & Statistiques

## Fichiers
- `css/views/collection.css`, `css/views/stats.css`
- `js/business/CollectionManager.js`, `js/UI/views/CollectionView.js`, `js/UI/views/StatsView.js`

## Spécifications

1. **`CollectionManager.js`** : croise les JSON de sets avec le store `collection` (`getCollectionView()`, complétion globale et par set).

2. **`CollectionView.js`**
   - Grille responsive de **toutes** les cartes des extensions.
   - Possédées : en couleur + badge `xN`. Non possédées : `filter: grayscale(100%) opacity(0.4)`.
   - Filtres : extension, rareté (1–5), style (Normal / Full Art), statut (Possédées / Manquantes) + recherche par nom.
   - Clic : modal grand format (illustration, date d'obtention `firstObtainedAt`, quantité).
   - Images via `I18n.resolveImagePath()`, libellés via `I18n.t()`. Chargement `loading="lazy"`.

3. **`StatsView.js`** (lit `user_state["stats"]` et `collection`)
   - Boosters ouverts : `stats.boostersOpened` (les cartes reçues par redeem/cadeau n'y comptent pas).
   - Complétion globale et par extension.
   - Répartition des tirages par rareté : `stats.drawsByRarity`, barres CSS natives.
   - Top Card : carte avec le plus grand `drawsByCard`.
