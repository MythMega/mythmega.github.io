# Instructions - Étape 2 : Synchronisation Temporelle & Quota (3 Boosters/Jour + Bonus)

## Objectif
Quota strict de 3 boosters/jour réinitialisé à **00:00:00 UTC**, contrôle temps par API externe, secours hors-ligne anti-triche. Le compte existe déjà (Étape 1). Le modèle de données est celui de `main.md` §2.

## Fichiers
- `js/business/DateSyncManager.js`
- `js/utils/EventBus.js`

## Spécifications

1. **`EventBus.js`** : pub/sub simple (`on`, `off`, `emit`). Événements : `QUOTA_UPDATED`, `CONNECTION_STATUS`.

2. **`DateSyncManager.js`**
   - **Appel réseau :** `https://worldtimeapi.org/api/timezone/Etc/UTC` (timeout court). Si échec, essayer un second fournisseur configurable, puis le mode hors-ligne.
   - **Reset :** compare le jour UTC (`YYYY-MM-DD`) à `quota.lastResetDay`. Si supérieur : `dailyRemaining = 3`, `lastResetDay = jour UTC`. **`bonusBoosters` (objet par set) n'est jamais modifié par le reset.**
   - **Ancrage (connexion réussie) :** stocke `timeAnchor = { apiUtcMs, perfNow: performance.now(), lastKnownUtcMs: apiUtcMs }`.
   - **Hors-ligne, même session :** `utcEstimé = apiUtcMs + (performance.now() − perfNow)`. `Date.now()` n'est jamais utilisé.
   - **Hors-ligne après rechargement de page :** `performance.now()` a été remis à zéro, l'ancrage est invalide. Le temps est **figé** à `lastKnownUtcMs`. Pas de reset possible tant que le réseau est absent. Documenter ce choix en commentaire.
   - Le temps estimé ne recule jamais : `max(estimé, lastKnownUtcMs)`. Mettre à jour `lastKnownUtcMs` à chaque estimation.
   - Rappel : IndexedDB est modifiable par l'utilisateur ; l'objectif est de bloquer la triche simple (horloge système), pas un attaquant déterminé.

3. **API exposée**
   - `async init()`
   - `async getRemainingBoosters(setId?)` → `{ daily, bonusBySet, bonusTotal, availableForSet }` (`availableForSet` = `daily + bonusBySet[setId]` si `setId` est fourni).
   - `async consumeBooster(setId)` → consomme d'abord `dailyRemaining`, puis `bonusBoosters[setId]` ; renvoie `false` si aucun des deux n'est disponible pour ce set.
   - `async addBonusBoosters(setId, n)` → incrémente `bonusBoosters[setId]` ; utilisé par Redeem (Étape 7) et Cadeaux (Étape 8). Refuser un `setId` inconnu des JSON de `settings/boosters/`.
   - `getFormattedTimeUntilReset()`
   - Chaque changement émet `QUOTA_UPDATED`.

4. Intégration dans `app.js` : `init()` après l'onboarding, mise à jour du header via `QUOTA_UPDATED`, horloge UTC qui tourne chaque seconde.

Génère le code complet de `DateSyncManager.js`, `EventBus.js` et l'intégration.
