# Instructions - Étape 6 : Sauvegarde `.save`, Import à l'accueil & Vue Paramètres

## Objectif
Système `.save` compressé/encodé (non lisible en clair, **ce n'est pas du chiffrement**), vue Paramètres complète (langue, thèmes, compte, sauvegarde). Branche le bouton "Importer" de l'onboarding.

## Fichiers
- `js/utils/Compression.js`, `js/classes/SaveFile.js`
- `js/UI/views/SettingsView.js`, `css/views/settings.css`

## Spécifications

1. **`Compression.js`** : `CompressionStream('deflate')` / `DecompressionStream('deflate')`.
   - Export : JSON → deflate → ArrayBuffer → Base64. Import : l'inverse. Gérer les gros buffers par morceaux pour le Base64.

2. **`SaveFile.js`**
   - `export()` : contenu = `{ version: 1, exportedAt, stores: { collection, user_state, redeemed_codes, gifts_received } }`. Donc **UUID, settings, quota, stats, giftSync et historique des cadeaux inclus**. Fichier `backup_cards_[DATE].save`.
   - `importFromFile(file)` : décompresse, **valide la structure** (version, stores présents, `user_state.account.uuid` présent et de format UUID, types des champs), puis écrase la base dans une transaction et recharge l'app. L'UUID restauré est celui de la sauvegarde.
   - Utilisée par le bouton "Importer" de l'onboarding **et** par Paramètres. Si un compte existe déjà, confirmation obligatoire par modal ("Les données actuelles seront remplacées").

3. **`SettingsView.js`** — sections :
   - **Langue** : FR / EN (`I18n.setLang`, application à chaud, sauvegarde dans `settings`).
   - **Thème** : **Sombre / Clair / Classic** (`ThemeManager.applyTheme`, sauvegarde dans `settings`). Les listes viennent de `config.json`, donc ajouter une langue ou un thème ne demande aucun changement de code.
   - **Compte** : affichage de l'UUID (lecture seule) + bouton "Copier". Texte explicatif : à communiquer pour recevoir des cadeaux.
   - **Sauvegarde** : Exporter, Importer, **Réinitialiser** (modal de confirmation ; supprime tout, UUID compris, puis retour à l'onboarding).
   - **Distributions** : emplacement réservé pour "Vérifier les distributions" et le lien "Historique des cadeaux" (implémentés à l'Étape 8).

Génère le code complet.
