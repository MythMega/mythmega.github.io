# Internationalisation (i18n)

## Vue d'ensemble

Pokefeet utilise un système d'internationalisation maison. Les traductions sont stockées dans des fichiers JSON et appliquées au DOM via des attributs `data-i18n`.

## Fichiers de traduction

```
translations/
├── fr.json    # Traductions françaises
└── en.json    # Traductions anglaises
```

### Format

```json
{
  "daily.types": "Type(s)",
  "daily.index": "Index",
  "daily.generation": "Génération",
  "daily.eggGroups": "Groupes d'oeuf",
  "daily.category": "Catégorie",
  "daily.correctAnswer": "Réponse correcte = +",
  "daily.pointsReward": "points",
  "daily.invalidName": "Nom invalide",
  "daily.alreadyTried": "Déjà essayé",
  "daily.newPokemon": "Nouveau Pokémon !",
  "daily.copied": "Copié dans le presse-papier",
  "daily.copyFail": "Impossible de copier",
  "daily.futureDaily": "Impossible de jouer un daily du futur",
  "types.fire": "Feu",
  "types.water": "Eau",
  "types.grass": "Plante",
  ...
}
```

Les clés sont organisées par module :
- `daily.*` — Mode Daily
- `weekly.*` — Mode Weekly
- `practice.*` — Mode Marathon/Entraînement
- `dex.*` — Pokédex
- `history.*` — Historique
- `stats.*` — Statistiques
- `profile.*` — Profil
- `types.*` — Noms des types Pokémon
- `ui.*` — Éléments d'interface génériques

## Modules

### `i18n-setup.js`

Configure le système de traduction au chargement de la page.

### `translate.js`

Fonctions de traduction :

```js
// Fonction principale
Translator.get(key, fallback)  // Retourne la traduction ou le fallback

// Raccourci
Translator.getLanguage()       // Retourne 'fr' ou 'en'
```

### `language-switcher.js`

Sélecteur de langue dans l'interface (généralement un bouton FR/EN).

### `apply-translations.js`

Parcourt le DOM et applique les traductions aux éléments avec l'attribut `data-i18n` :

```html
<span data-i18n="daily.types">Type(s)</span>
```

## Utilisation dans le code

### Dans le JavaScript

```js
// Avec fallback
const label = Translator.get('daily.types', 'Type(s)');

// Sans fallback (retourne la clé si non trouvée)
const label = Translator.get('daily.types');
```

### Dans le HTML

```html
<!-- Le texte sera remplacé par la traduction -->
<button data-i18n="daily.submit">Valider</button>
```

### Pour les textes dynamiques

```js
// Pour les badges de types (HTML)
const t1Badge = `<span class="type-badge t-${t1.toLowerCase()}">${Translator.get('types.' + t1.toLowerCase(), t1)}</span>`;
```

## Ajouter une nouvelle traduction

1. Ajouter la clé dans `translations/fr.json` et `translations/en.json`
2. Utiliser `Translator.get('maCle', 'Fallback FR')` dans le code
3. Optionnellement, ajouter `data-i18n="maCle"` dans le HTML

## Bonnes pratiques

- Toujours fournir un **fallback en français** (langue par défaut)
- Organiser les clés par module (`daily.*`, `practice.*`, etc.)
- Pour les types Pokémon, utiliser `types.nomdutype` (ex: `types.fire`)
- Les clés sont en anglais (ex: `daily.types` plutôt que `daily.typesFr`)
